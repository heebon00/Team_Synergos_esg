# Reuse Skill (Simplicity First)

This skill enforces finding existing styles and UI structures to reuse, avoiding code bloat.

## Procedures

1. **Check tokens.css**: Verify if requested colors, spacing, and radii already exist as CSS tokens.
2. **Scan Existing markup**: Look for duplicate patterns in the file system (e.g. headers, footers, button classes).
3. **Map to Assets**: Use existing icons (`assets/icons/`) or hero banners (`assets/img/`) following naming conventions before downloading new ones.
