# Clarify Skill (Think Before Coding)

This skill guides the clarification of requirements before writing code, checking for ambiguity in the layout and content.

## Procedures

1. **Read Figma Specs**: Parse components and parameters (colors, sizing, gaps) from the Figma file data.
2. **Formulate Questions**: If any text, styling, or responsive behavior is missing or ambiguous, document it.
3. **Verify Constraints**: Confirm target elements (e.g., in `index.html` segment anchors) and variables before proceeding.
