# Evaluate Skill (Goal-Driven Execution)

This skill mandates self-testing and auditing the final UI output.

## Procedures

1. **Verify No Raw Values**: Double-check the changes to ensure there are no accidental hex codes, px units, or arbitrary classes.
2. **Review Layout Matching**: Verify the spacing, alignments, and fonts against the Figma spec.
3. **Accessibility (A11y)**: Ensure keyboard navigability (focus outline), logical heading structures (`h1`-`h6`), and screen reader helpers (`sr-only-hide`).
